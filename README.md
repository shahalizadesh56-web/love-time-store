# LOVE TIME — Backend Starter

این پروژه اسکلت بک‌اند واقعی فروشگاه LOVE TIME است.

## امکانات
- Node.js + Express
- SQLite برای شروع سریع
- API محصولات
- ایجاد سفارش
- محاسبه قیمت در سمت سرور
- ذخیره سفارش و اقلام سفارش
- وضعیت پرداخت
- endpoint آماده برای callback درگاه

## اجرا
1. Node.js 20+ نصب کنید.
2. این پوشه را باز کنید.
3. `npm install`
4. `.env.example` را به `.env` کپی کنید.
5. `npm run dev`
6. آدرس `http://localhost:3000/api/health` را باز کنید.

## اتصال درگاه واقعی
اطلاعات پذیرنده/مرچنت را داخل `.env` قرار ندهید مگر از طریق روش امن سرور. برای هر درگاه باید API رسمی همان provider استفاده شود. بعد از دریافت credentials، توابع request-payment و verify-payment باید در سرور تکمیل شوند.

**نکته:** تا وقتی credentials و provider مشخص نشده، پرداخت عمداً دمو است و هیچ تراکنش بانکی واقعی انجام نمی‌دهد.
